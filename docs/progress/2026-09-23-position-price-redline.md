## 1. 位置式触发价位（已修复、已上线）

**缺口**：「股价仍处于筹码加权平均成本 84.28 元下方，那么可小幅试仓」这类句子不带「跌破 / 站上」这些触发动词，`TRIGGER_PRICE_RE` 抓不到。2026-08-31 指南针那篇是手工改掉的，规则一直没补。

**标定**：先对 179 篇存量扫「价位 + 上方 / 下方 / 之上 / 之下 / 以上 / 以下」的全部写法。只加「处于」一个词一条都抓不到，真违规写的是「可在 45 元下方分批试仓」「股价重回筹码加权成本 84.28 元上方」「站回 250.80 元之上」「挑战 50 元上方」「下探 220 元以下」「区间参照 50% 分位 54.00 元上方」「→ 45 元下方分批」。动词表照这些原文收。

**规则**（`scripts/research-qc.js` 的 `POSITION_PRICE_RE` + `positionTriggers()`）：判据是价位后紧跟方位词；复用原有的条件句 / 操作结论 / 过去时 / 引用 / 基准价 / 商品价 / EPS 豁免，另加三类只对位置式生效的豁免，都是存量里标定出的误报：
- 主语是筹码刻度本身（「持仓成本在 329.00 元以上」）；
- 主语是产品价格（「光模块价格将维持在 700 美元以上」），但「股价 / 市价 / 行情价格」不算；
- 同一分句的主语是现价 / 收盘价（「当前价 269.33 元（日期）位于成本线 241.20 元之上」）。

存量结果：误报修到 0，真违规 11 篇。每条豁免和守卫都做过变异验证（拆掉就有测试变红）。

**存量整改**：11 篇的 report.html / notes.md 已改成相对表述（1 篇本站自产的三花 06-05，10 篇 Stocks 导入的）。同一段情景路径里 QC 没抓到的同类价位也一并改了，例如括号写法「筹码加权成本（253 元附近）上方」「15% 分位（220.40）」。Obsidian 里的全文笔记是私人的，没动。

**导入侧同步**（`services/stocks-import/src/price-anchor.js` 形态三）：11 篇里 10 篇是 Stocks 导入的，只改质检的话每天导入会有一部分被搁置、发报警。改写器现在也处理位置式：**判定直接调 `positionTriggers`**，不另写词表，所以 QC 放行的现状陈述改写器也不碰；只剥「有锚」的数值，裸价位和区间照旧留给 QC 搁置。Stocks 原文里常见的 `**…910.20 元**下方` 这种加粗写法也认，剥完加粗符号仍然配对。

**真实数据回放**：从 Mac mini 活库只读拉出全部 145 篇 Stocks 报告原文，跑「清洗 → 改写 → 渲染 → 质检」全链路：12 篇含位置式，改写器自动剥掉 8 篇（含指南针当年那句），7 篇仍会被搁置；其中只因新规则才被搁置、旧规则下能过的有 4 篇，折算约 3% 的新增搁置率。仍会被搁置的都是没有锚的裸价位，按 Stocks SKILL 本来就不该这么写；对应的报告要么早已 `.dropped`，要么就是本次手改的那几篇。

**连带**：`scripts/anchor-candidates.js`（锚名对账）原来只认「具体触发价位」一类。加了新类别后，它曾在 11 篇被拦的情况下报「✅ 当前没有被拦下的价位」，属于假绿，现已两类都认。stock SKILL §4.9 第 3 条补了一句位置式写法。Stocks 仓库不用改：它的 SKILL 早已要求「价位先写锚」「K 节 path 不许有价位」。

## 3. 09-18 数字核查修复的实效（核对完成；发现的问题待修，见 §4）

- **待质证清单变短了**：合计从 379 条降到 310 条。其中 53 条来自新加的英文 billion / million 写法，逐条对过原文，都是真命中；16 条来自「数字之间保留空格」，其中 12 条真命中、3 条假命中、1 条疑似巧合。没有任何一条从「已找到」退回「待质证」。

## 4. 待办

1. **09-18 修复带出的假「已找到」（待修）**：`containsNumber` 的右边界不排除「小数点 + 数字」，整数 18 能命中 18.15；换算那一档也不看单位。数字不再粘连以后，新浪侧栏、PDF 表格里的独立小数和股票代码被当成了命中：left-side「18 亿港元」命中侧栏「920015 18.15」，智谱「20 亿元」命中 PDF 表格「20.94」，nvidia「92 亿美元」命中侧栏代码「920288」。修的时候要注意：全量里「整数命中小数前半」共 26 处，大多是合理的四舍五入（382 对 382.4），不能一刀切。复现：`containsNumber(normalizePage("锦华新材920015 18.15"),"18")` 现在返回 true。
2. **港股「百萬港元」没有对应换算（待修，修复前就有）**：智谱 313.75 亿港元（页面写 31,374.95 百萬港元）仍在待质证里。
3. **失败原因写错（待修，修复前就有）**：`static.sse.com.cn` 的 PDF 链接实际回的是 200 的反爬 JS 挑战页，note 却写「缺 pdftotext 或为扫描件」，容易让人误以为 runner 又缺 pdftotext。
4. **只是说明、不用修**：美股披露源（sec.gov、businesswire 等）一律 403，换 http 也是 403，vertiv 那篇 51 个数字未测，前后一样。
5. **只是说明**：K 节 path 里不带方位词的价位（「在 A 元与 B 元之间」以外的陈述句写法）两道检查仍然都够不着，只能靠写作端。本次只顺手改了 11 篇里同段落的同类写法，没有对全部存量系统排查。
